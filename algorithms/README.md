# Algorithms Implementations

This directory contains clean, to-the-point references and implementations of fundamental algorithms in Python, designed for Competitive Programming (CP) and Data Structures & Algorithms (DSA).

---

## Sorting Algorithms

Sorting algorithms arrange elements of a list in a specific order (typically ascending or descending).

Currently documented algorithms:

- **Bubble Sort:** [bubble_sort.py](01_sorting/bubble_sort.py) - Simple adjacent swap-based sorting algorithm.
- **Selection Sort:** [selection_sort.py](01_sorting/selection_sort.py) - Simple minimum-selection sorting algorithm.
- **Insertion Sort:** [insertion_sort.py](01_sorting/insertion_sort.py) - Simple insertion-based sorting algorithm.
- **Merge Sort:** [merge_sort.py](01_sorting/merge_sort.py) - Divide and Conquer-based stable sorting algorithm.
- **Quick Sort:** [quick_sort.py](01_sorting/quick_sort.py) - Partition-based fast sorting algorithm.

---

## Searching Algorithms

Searching algorithms locate the position of a target element within a collection.

Currently documented algorithms:

- **Binary Search:** [binary_search.py](02_searching/binary_search.py) - Logarithmic search on sorted arrays, implemented iteratively and recursively.
