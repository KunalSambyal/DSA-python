# Algorithms Implementations

This directory contains clean, to-the-point references and implementations of fundamental algorithms in Python and C++, designed for Competitive Programming (CP) and Data Structures & Algorithms (DSA).

---

## [01. Sorting Algorithms](01_sorting/README.md)

Sorting algorithms arrange elements of a list in a specific order (typically ascending or descending).

Currently documented algorithms:

- **Bubble Sort** - Simple adjacent swap-based sorting algorithm.
- **Selection Sort** - Simple minimum-selection sorting algorithm.
- **Insertion Sort** - Simple insertion-based sorting algorithm.
- **Merge Sort** - Divide and Conquer-based stable sorting algorithm.
- **Quick Sort** - Partition-based fast sorting algorithm.

---

## [02. Searching Algorithms](02_searching/README.md)

Searching algorithms locate the position of a target element within a collection.

Currently documented algorithms:

- **Linear Search** - Sequential search on unsorted/sorted collections.
- **Binary Search** - Logarithmic search on sorted arrays, implemented iteratively and recursively.
